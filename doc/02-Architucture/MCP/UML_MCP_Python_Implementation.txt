note right of GhostMcpRuntime

Creates and connects:

- low-level MCP Server
- Streamable HTTP Session Manager
- Starlette application
- exact /mcp route

Registers:

- tools/list
- tools/call

end note


note right of GhostMcpApplication

Boundary between the MCP protocol
and the GHOST tool implementation.

Validates the tool name,
invokes the tool and converts
GhostToolResult to CallToolResult.

end note


note right of GhostEngineerPromptTool

call():

1. validates prompt_text
2. invokes the runner
3. creates GhostToolResult

call_sanitized():

- catches public tool errors
- returns isError = true
- hides internal exceptions

end note


note right of PromptEngineeringRunner

One request:

1. creates fresh SuperPrompt
2. executes preprocess()
3. verifies preprocessed stage
4. creates A2PromptShaper
5. executes A2 version 003
6. verifies same SuperPrompt
7. verifies a2 stage
8. returns prompt_ready

end note


note right of AuthModule

Implemented authentication boundary.

Not currently imported or called
by server.py.

end note


note right of InMemoryRateLimiter

Implemented fixed-window limiter.

Not currently imported or called
by server.py.

end note
