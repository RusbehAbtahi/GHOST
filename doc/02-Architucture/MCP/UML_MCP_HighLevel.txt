note right of Route53

Route 53 resolves the public
domain name to the EC2 public IP.

It does not carry or forward
the HTTPS request.

end note


note right of Runtime

GhostMcpRuntime is implemented
inside server.py.

It creates and connects

- Starlette application
- exact mcp route
- Session Manager
- low-level MCP Server

end note


note right of Uvicorn

Uvicorn, Starlette,
StreamableHTTPSessionManager
and the low-level MCP Server
are external library objects.

server.py instantiates,
configures and connects them.

end note


note right of ApplicationBoundary

GhostMcpApplication is implemented
inside server.py.

Architecturally, it forms the boundary

Server Interface
- validates and dispatches the MCP call

Server
- executes the GHOST tool logic

end note


note right of Authentication

auth.py exists inside
ragstreammcp.

It is not yet called
by server.py.

end note


note right of RateLimiter

rate_limiter.py exists inside
ragstreammcp.

It is not yet called
by server.py.

end note


note right of Entity5

Version 1 executes only

fresh SuperPrompt
- PreProcessing
- A2 PromptShaper
- engineered prompt

It does not execute

Retrieval

A3
A4
MemoryMerge

end note
